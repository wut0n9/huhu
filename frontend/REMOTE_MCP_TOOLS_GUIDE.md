# 远程MCP工具功能指南

## 功能概述

新增的远程MCP工具功能允许用户在MCP工具选择器中添加、编辑和删除远程MCP工具。这些工具通过URL连接到远程MCP服务器，扩展了系统的工具能力。

## 主要功能

### 1. 添加远程MCP工具

- 点击MCP工具选择器按钮打开工具选择页面
- 在页面顶部点击"添加远程工具"按钮
- 填写以下信息：
  - **工具名称**: 自定义的工具名称（最多50字符）
  - **工具描述**: 工具功能的详细描述（最多200字符）
  - **工具URL**: 远程MCP服务器的URL地址
  - **工具图标**: 从预定义图标中选择
  - **工具分类**: 选择合适的分类（远程工具、API服务等）

### 2. 查看远程工具

- 远程工具在工具列表中会显示蓝色的"远程"标签
- 与本地工具一起按分类显示
- 支持正常的选择和取消选择操作

### 3. 编辑远程工具

- 在工具列表中，远程工具右侧有编辑按钮（铅笔图标）
- 点击编辑按钮打开编辑表单
- 可以修改除ID外的所有信息
- 保存后立即生效

### 4. 删除远程工具

- 在工具列表中，远程工具右侧有删除按钮（垃圾桶图标）
- 点击删除按钮会弹出确认对话框
- 确认删除后，工具将从列表中移除
- 如果工具已被选择，也会从选择列表中移除

## 数据存储

- 远程工具信息保存在浏览器的localStorage中
- 存储键名：`mcp_remote_tools`
- 数据格式：JSON数组，包含所有远程工具信息
- 支持跨会话持久化

## 技术实现

### 类型定义扩展

```typescript
export interface MCPTool {
  id: string;
  name: string;
  description: string;
  icon: string;
  category: string;
  url?: string; // 远程MCP工具的URL
  isRemote?: boolean; // 标识是否为远程工具
}
```

### 主要组件

1. **MCPToolSelector**: 主工具选择器组件
   - 集成了远程工具管理功能
   - 支持本地工具和远程工具的统一显示

2. **AddRemoteMCPTool**: 添加/编辑远程工具的子页面
   - 表单验证和数据处理
   - 支持添加和编辑两种模式

### 本地存储管理

```typescript
// 保存远程工具到本地存储
const saveRemoteToolsToStorage = (tools: MCPTool[]) => {
  localStorage.setItem('mcp_remote_tools', JSON.stringify(tools));
};

// 从本地存储加载远程工具
useEffect(() => {
  const savedTools = localStorage.getItem('mcp_remote_tools');
  if (savedTools) {
    setRemoteTools(JSON.parse(savedTools));
  }
}, []);
```

## 注意事项

1. **URL验证**: 系统会验证输入的URL格式是否正确
2. **数据持久化**: 远程工具信息仅保存在本地浏览器中
3. **工具标识**: 远程工具会显示特殊的"远程"标签以区分本地工具
4. **操作权限**: 只有远程工具支持编辑和删除操作
5. **分类管理**: 远程工具支持多种预定义分类

## 故障排除

### 常见问题

1. **工具不显示**: 检查localStorage是否被清除
2. **URL无效**: 确保输入的是完整的有效URL
3. **编辑失败**: 检查网络连接和表单验证
4. **删除确认**: 删除操作需要用户确认，无法撤销

### 调试方法

1. 打开浏览器开发者工具
2. 查看Console面板的错误信息
3. 检查Application > Local Storage中的数据
4. 验证组件状态和props传递
